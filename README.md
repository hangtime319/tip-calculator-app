# Tip Calculator App

A fully functional, responsive tip and total bill calculator with real-time updates and input validation.

## Description

This project is a solution to the "Tip calculator app" challenge from Frontend Mentor. The main objective was to build a complete, interactive web application. This project is a great example of using **JavaScript** for form handling, performing real-time calculations, and providing robust input validation. It demonstrates how to create a seamless user experience that responds instantly to user input, handling both success and error states gracefully.

## Technologies Used

* **HTML5:** For creating the semantic structure of the application form and the display sections for the results.
* **CSS3:** Used for all the styling, including the responsive layout, interactive button states, and visual feedback for error messages.
* **JavaScript:** This is the core technology that powers the application. It handles:
    * Capturing user inputs from the form fields.
    * Performing all calculations for tip and total per person.
    * Managing the logic for both preset tip buttons and the custom input field.
    * Real-time updating of the results as values change.
    * Validating inputs to prevent errors (e.g., division by zero).

## Installation

This is a static frontend project, so no complex setup is required. To get a local copy, simply follow these steps:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/hangtime319/tip-calculator-app.git](https://github.com/hangtime319/tip-calculator-app.git)
    ```
2.  Open the `index.html` file in your preferred web browser to view the application.

## Usage

This application is designed for calculating tips and splitting the total bill. Users can input the bill amount, select a tip percentage from the buttons or enter a custom value, and specify the number of people. The results for "Tip Amount" and "Total per person" are updated automatically on the right side of the screen.

## Features

* **Real-time Calculation:** The results are updated instantly as the user types or selects options.
* **Input Validation:** The app provides a clear error message if the number of people is set to zero.
* **Interactive Form:** Users can easily select a tip percentage or input their own value.
* **Responsive Design:** The layout adapts to look great on all screen sizes, from mobile phones to desktops.
