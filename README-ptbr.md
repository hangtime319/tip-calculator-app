# Aplicativo de Calculadora de Gorjeta

Uma calculadora de gorjeta e total da conta totalmente funcional e responsiva, com atualizações em tempo real e validação de entrada.

## Descrição

Este projeto é uma solução para o desafio "Aplicativo de calculadora de gorjeta" do Frontend Mentor. O objetivo principal foi construir uma aplicação web completa e interativa. Este projeto é um ótimo exemplo de como usar **JavaScript** para lidar com formulários, realizar cálculos em tempo real e fornecer uma validação de entrada robusta. Ele demonstra como criar uma experiência de usuário fluida que responde instantaneamente às ações do usuário, lidando com estados de sucesso e erro de forma elegante.

## Tecnologias Usadas

* **HTML5:** Para criar a estrutura semântica do formulário da aplicação e as seções de exibição dos resultados.
* **CSS3:** Usado para toda a estilização, incluindo o layout responsivo, os estados interativos dos botões e o feedback visual para mensagens de erro.
* **JavaScript:** Esta é a tecnologia principal que alimenta a aplicação. Ela lida com:
    * A captura das entradas do usuário nos campos do formulário.
    * A realização de todos os cálculos para a gorjeta e o total por pessoa.
    * O gerenciamento da lógica tanto para os botões de gorjeta predefinidos quanto para o campo de entrada personalizado.
    * A atualização em tempo real dos resultados conforme os valores mudam.
    * A validação das entradas para prevenir erros (por exemplo, divisão por zero).

## Instalação

Este é um projeto de frontend estático, então não é necessária uma configuração complexa. Para obter uma cópia local, basta seguir estes passos:

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/hangtime319/tip-calculator-app.git](https://github.com/hangtime319/tip-calculator-app.git)
    ```
2.  Abra o arquivo `index.html` no seu navegador da web preferido para visualizar a aplicação.

## Uso

Esta aplicação foi projetada para calcular gorjetas e dividir o valor total da conta. Os usuários podem inserir o valor da conta, selecionar uma porcentagem de gorjeta nos botões ou inserir um valor personalizado, e especificar o número de pessoas. Os resultados para "Valor da Gorjeta" e "Total por pessoa" são atualizados automaticamente no lado direito da tela.

## Funcionalidades

* **Cálculo em Tempo Real:** Os resultados são atualizados instantaneamente conforme o usuário digita ou seleciona opções.
* **Validação de Entrada:** A aplicação fornece uma mensagem de erro clara se o número de pessoas for zero.
* **Formulário Interativo:** Os usuários podem selecionar facilmente uma porcentagem de gorjeta ou inserir seu próprio valor.
* **Design Responsivo:** O layout se adapta para ficar ótimo em todos os tamanhos de tela, de celulares a desktops.
